## Protocols (keep these)

- **Gate before every PR** (in the step worktree):
  `LINT_MODE=STRICT ./Scripts/lint.sh` (auto-formats — run before the final
  test pass), `swift build && swift test`, then
  `swift run fcpxml-diff schema-completeness Tests/FCPKitTests/TestData --fail-if-total-exceeds 0`.
- **Stacked PRs:** base = predecessor branch; merge bottom-up only;
  squash-merge unmodified and delete the head branch so GitHub retargets the
  child PR to `v0.1.x` (if not deleted, retarget manually with
  `gh pr edit <n> --base v0.1.x`).
- **Merges into `v0.1.x` don't auto-close issues** (non-default branch): after
  each merge, ff `v0.1.x`, re-run the gate there, close the issue with the
  landing SHA.
- **Fix propagation:** a post-branch fix on step *k* is merged (plain `git
  merge`, never rebase/force-push) into every descendant branch immediately.
- PR bodies: `Part of #N`, scope, pasted gate results, merge-train note.
